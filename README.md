# JavaScript To-Do List

A lightweight to-do list that runs in your browser. Add tasks, mark them complete, and remove them; your task list is saved in the browser's local storage.

## Features

- Add tasks using the button or the Enter key.
- Mark tasks complete and undo completion.
- Remove tasks you no longer need.
- Keep tasks between visits using browser local storage.
- No dependencies, build step, or account required.

## Get started

### Requirements

A modern web browser with JavaScript and local storage enabled.

### Run the app

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Type a task and select **Add Task** (or press Enter).

Select **Complete** to mark a task done, **Undo** to restore it, or **Remove** to delete it. Tasks are stored in the local storage of the browser you use, so they are not synced across browsers or devices.

The app is made with plain HTML, CSS, and JavaScript. There are no dependencies or package installation steps.
